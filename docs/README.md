# 演示文件目录

此目录用于存放项目的演示文件，包括：

- `demo.gif` - 软件运行演示动画
- `screenshot1.png` - 界面截图1
- `screenshot2.png` - 界面截图2
- `video_thumbnail.png` - 视频缩略图

## 如何制作演示文件

请参考 README.md 中的"演示视频"部分，那里有详细的制作指南。

## 快速开始

如果你已经制作了演示文件，请将它们放到这个目录中：

1. 将GIF文件重命名为 `demo.gif`
2. 将截图文件重命名为 `screenshot1.png`, `screenshot2.png` 等
3. 确保文件大小合理（GIF建议小于5MB）

## 注意事项

- 请确保演示文件展示了软件的核心功能
- GIF时长建议20-40秒
- 图片尺寸建议宽度800像素左右
- 避免在演示中显示敏感信息
